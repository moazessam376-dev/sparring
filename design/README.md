# Design

Working files for the sparring desktop application. Each `.dc.html` is one artboard
on a shared canvas; `canvas.json` lays them out. `_shared.py` holds the style block
every artboard repeats, since artboards cannot share CSS. `sparring-screens.html` is
generated by re-seeding and is not edited by hand.

Published at https://claude.ai/code/artifact/1e85a088-a8f7-4712-a150-bbd37fabcdc8
Directions, kept for the record, at https://claude.ai/code/artifact/b5dc4601-730c-47b9-a9f4-f16323e3834b

| File | Screen |
| --- | --- |
| `Survey.dc.html` | Pointing sparring at a repository and confirming what it found |
| `ProjectMap.dc.html` | One project's parts, with the cross-cutting constraints drawn as bands |
| `Main.dc.html` | The hub: projects and topics as one graph |
| `LessonPlayer.dc.html` | A lesson, one part at a time, each ending in a check |
| `DrillRunner.dc.html` | The question loop: commit, grade, contest |
| `Standing.dc.html` | Gaps, decay, and whether the schedule is calibrated |
| `Components.dc.html` | The catalogue an agent fills in |

## The material

Both panes are glass at different densities over a lit, slowly drifting ground.
The sidebar is thin at 0.58 so the ground reads through it. The content pane is
dense at 0.86 so nothing competes with text. Apple reserves this material for
navigation and says not to run it through content; the density split is how both
that and the brief are honoured. Do not take the content pane below about 0.78.

Ground `#0b0c0c`, text `#e2e5e4`, muted `#979e9d`, faint `#626a69`, hairline
`rgba(255,255,255,0.06)`, accent `#9ee87d`, warning `#e8c97d`, danger `#e88d7d`.
Archivo for interface text, DM Mono for technical content only.

Motion lives in the shell, never beside something being learned. The ground
drifts on a 54 second cycle and panels rise once on appearance. Both stop under
`prefers-reduced-motion`.

## Three rules the screens exist to hold

- Nothing is revealed before the candidate commits, the grounding file included.
- Every estimate is drawn with how little it is worth. The pale band behind a bar is its uncertainty, and on a thinly evidenced topic it is wider than the bar.
- A part the survey could not verify is drawn dashed and marked, never dropped.
