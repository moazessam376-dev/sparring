TITLE

ONE PLAIN SENTENCE THAT WIRES THE WHOLE THING.

Sequence numbers

Every message gets a number before anyone sees it.

  1. 1

    Client A sends a message to the server it is connected to.

  2. 2

    Redis hands out the next number for that room (INCR).

  3. 3

    Every client receives the message with its number.

Decision: the server numbers messages

  1. What we do

    Redis gives each room one counter. Every message takes the next value.

  2. The other way

    Use the clock, or let each client number its own messages.

  3. Why not here

    Two servers have two clocks. Two clients cannot order each other.
