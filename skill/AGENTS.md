# Sparring agent rules

When a user asks for a repository survey, project map, lesson, drill, quiz, mock interview, or grade review, load [SKILL.md](SKILL.md). Evidence: `docs/2026-09-12-sparring-as-software-design.md`, sections 3.1 and 4; `docs/research/2026-09-10-learning-science.md`, findings 1 and 8.

Select one mode from its table. Load [references/interviewer-rules.md](references/interviewer-rules.md) for every mode. Load [references/components.md](references/components.md) before writing lesson content. Evidence: `docs/research/2026-09-10-learning-science.md`, findings 1, 5, and 9.

Apply the selected reference as an ordered procedure. Keep claims grounded, keep rubrics hidden until commitment, and record every graded answer. Evidence: `docs/research/2026-09-12-large-repository-survey.md`, findings 10 and 11; `docs/research/2026-09-10-learning-science.md`, findings 1, 8, 9, and 11.

Use the MCP server tools named by the selected reference. Return the learner-facing result only after the required server submission or record succeeds. Evidence: `docs/2026-09-12-sparring-as-software-design.md`, sections 3.1 and 4; `docs/research/2026-09-10-learning-science.md`, findings 1, 8, and 9.
