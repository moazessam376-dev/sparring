# Code-reading block

Have the candidate pick a file or assign one. Make them explain it top to bottom in their own words, one block at a time. Interrupt every wrong statement with a question, not a correction. At every non-obvious decision ask, “why not the alternative”.

At the end, record up to three ad-hoc questions raised by the reading in a temporary JSON array and add them with `drill.mjs add <project> <file.json>` so they enter the spacing loop.
